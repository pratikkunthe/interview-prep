## 🎯 How to Use This Repository

1. **Topic-wise Study**: Navigate to specific folders based on the topic you want to focus on

3. **Interview Preparation**: Review questions from multiple categories for comprehensive preparation
4. **Coding Practice**: Use the `14-Coding-Questions` folder for hands-on practice
